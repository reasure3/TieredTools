# Tiered Tools 모드

이 모드는 마인크래프트의 도구 시스템을 완전히 새롭게 바꿉니다. 이제 더 이상 상위 등급의 도구를 직접 조합할 수 없으며, 대신 대장장이 작업대를 통해 도구를 단계별로 강화해야 합니다.

## 📝 Key Features

- **단계별 강화**: 나무 도구 및 가죽 갑옷에서 시작하여 네더라이트 단계까지 차근차근 업그레이드하는 새로운 시스템을 도입합니다.
- **기존 조합법 삭제**: 나무 도구와 가죽 갑옷을 제외한 모든 도구 및 갑옷의 기존 조합법이 삭제됩니다.
- **새 대장장이 형판**: 각 단계별로 강화하는데 필요한 고유한 '강화 대장장이 형판'이 추가됩니다.
- **신규 블록: '임시 대장장이 작업대'**: 게임 초반에 사용할 수 있는 돌로 만든 대장장이 작업대가 추가됩니다. 사용 시 일정 확률로 파괴될 수 있습니다.
- **신규 블록: '복구 작업대'**: 장비를 이전 단계로 되돌릴 수 있는 새로운 작업대입니다.
- **무한 내구도 (기본값)**: 모든 장비는 기본적으로 내구도가 무한합니다.

## 🚀 게임 플레이 가이드

### 1. 시작하기
먼저 기본적인 나무 도구를 제작하세요. 모든 여정은 나무 도구에서 시작됩니다!

### 2. 돌 제련대 제작 및 사용 
초반 강화를 위해 **임시 다장장이 작업대**를 제작해야 합니다. 임시 대장장이 작업대는 사용 시 내구도가 닳으며 파괴될 수 있으니 주의하세요!

### 3. 강화 방법
도구 강화는 제련대 UI에서 이루어집니다.

> **[이전 단계 도구] + [강화 대장장이 형판] + [강화 재료] = [다음 단계 도구]**

자세한 레시피는 [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) 모드를 참고해주세요.

### 4. 단계별 강화 대장장이 형판 및 재료

| 강화 대장장이 형판       | 대장장이 형판 획득 방법         |
|:-----------------|:----------------------|
| 돌 강화 대장장이 형판     | **제작**: 돌 x8 + 막대기 x1 |
| 사슬 강화 대장장이 형판    | 오버월드 상자               |
| 철 강화 대장장이 형판     | 대장간 상자                |
| 금 강화 대장장이 형판     | 보루 잔해 상자              |
| 다이아몬드 강화 대장장이 형판 | 주민 거래                 |
| 네더라이트 강화 대장장이 형판 | 엔더 월드 상자              |

**※ 중요:** 네더라이트 강화 대장장이 형판은 더 이상 보루 잔해에서 나오지 않으며, 엔더 월드에서만 찾을 수 있습니다.

### 5. 도구 되돌리기

실수로 도구를 강화했거나 이전 단계의 도구가 필요한 경우, 복구 작업대를 사용할 수 있습니다.
복구 작업대에 도구를 올려놓으면 즉시 이전 단계의 도구로 변환됩니다. (예: 철 곡괭이 → 돌 곡괭이)

## ⚙️ 설정 (Config)

**(아래 기능은 추후 업데이트로 추가될 예정입니다.)**

- `durabilityMode`: 도구의 내구도 작동 방식을 설정합니다.
    - `Infinite` (기본값): 모든 도구의 내구도가 무한이 됩니다.
    - `Downgrade`: 도구에 내구도가 적용되며, 내구도가 모두 소진되면 이전 단계의 도구로 약화됩니다.
    - `Vanilla`: 마인크래프트 기본 내구도 시스템을 그대로 사용합니다. (도구가 파괴되면 사라짐)
